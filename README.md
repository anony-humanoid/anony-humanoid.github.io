# OmniClone project page

Static, anonymous research project website for **OmniClone: A Robust, All-Around Whole-Body Humanoid Teleoperation System**.

Open `index.html` directly or serve the directory with `python3 -m http.server 8000` and visit http://localhost:8000. No build step or JavaScript dependencies are required. Google Fonts are optional; system fonts are used when unavailable.

- `index.html`: research narrative, demonstrations, and document links.
- `style.css`: responsive ivory, ink, and teal design.
- `script.js`: demonstration filters, operator selection, and video playback coordination.
- `resources/RAL27_OmniClone.pdf`: main paper.
- `resources/RAL27_OmniClone_supp.pdf`: supplementary material.
- `resources/video/`: demonstration videos, including the updated overview.
- `resources/posters/`: lightweight video preview frames.

Videos use native accessible controls and load on demand. The research content, PDF links, and demonstration gallery remain available without JavaScript; operator alternatives are linked in the no-script fallback.

Publish the repository root through the existing GitHub Pages configuration.
